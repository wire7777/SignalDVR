Storage

Leave a field blank to use the default folder under SignalDVR's install directory. When you save, SignalDVR checks that each path exists (creating it if needed) and is writable. Changes take effect after you restart SignalDVR - and existing recordings/buffer/thumbnail files are not moved automatically, so move them yourself first if you're relocating storage.
